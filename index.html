01 · 功能

六大核心能力

一行指令触发，从文字到语音消息，全链路打通。

A

双维度音色面板

「我的音色」字母索引 + 500+ 公开中文音色按评分排序。支持实时搜索，一键切换。

B

音色即时试听

每个音色附带样音按钮，后台异步下载 → MediaPlayer 播放，选中状态即时切换。

C

API Key 管理

图形化输入 Key，点击跳转 fish.audio 官网获取，长按复制。config.prop 持久化存储。

D

一键合成发送

POST /v1/tts → s2-pro → 流式读取 mp3 → 转 silk → sendVoice() 发送语音消息。

E

30 分钟智能缓存

ConcurrentHashMap + 时间戳校验，TTL 30 分钟。避免重复请求 API，重启即用。

F

纯原生 UI，零依赖

Dialog + LinearLayout + GradientDrawable。dp 自适应全部屏幕，无任何第三方库。

转语音

05 · 源码

核心片段

DC() — 接收文字，POST 请求 TTS 接口，流式读取 mp3 并缓存。

fish-audio-tts.java
void DC(String x, View b) {
    toast("正在转换…");
    new Thread(() -> {
        try {
            var r = new JSONObject();
            r.put("text", x);
            r.put("reference_id", a0);         // 音色 ID
            r.put("format", "mp3");
            r.put("normalize", true);

            var url = new URL("https://api.fish.audio/v1/tts");
            var cn = (HttpURLConnection) url.openConnection();
            cn.setRequestMethod("POST");
            cn.setDoOutput(true);
            cn.setRequestProperty("Authorization", "Bearer " + a2);
            cn.setRequestProperty("Content-Type", "application/json");
            cn.setRequestProperty("model", "s2-pro");

            // 发送 JSON → 流式读取 mp3 → 存储本地
            var o = cn.getOutputStream();
            o.write(r.toString().getBytes("UTF-8"));
            o.flush(); o.close();

            var mp = cacheDir + "/tts_" +
                      System.currentTimeMillis() + ".mp3";
            var fo = new FileOutputStream(mp);
            var ins = cn.getInputStream();
            byte[] bf = new byte[8192];
            int nn;
            while ((nn = ins.read(bf)) != -1)
                fo.write(bf, 0, nn);
            fo.close(); ins.close(); cn.disconnect();

            s("last_mp3", mp);                // 持久化路径
            b.post(() -> toast("转换成功"));
        } catch (Exception e) {
            b.post(() -> toast("转换失败"));
        }
    }).start();
}

06 · 架构

模块分解

六个模块，职责清晰，零第三方依赖。

1

配置持久层

g() / s() 封装 Properties 读写，config.prop 存储 Key 与音色。onLoad 自动加载。

config.prop
2

UI 工厂函数

M() Dialog · T() TextView · R()/B() GradientDrawable。dp() 自适应密度。

dp() · T() · R() · B()
3

缓存控制器

ConcurrentHashMap + 时间戳，TTL 30 分钟（V=1800000L）。过期自动刷新。

V = 1800000L
4

音频处理管线

MediaPlayer 播放 → mp3ToSilk() 转换 → sendVoice() 发送语音消息。

MediaPlayer · sendVoice()
5

音色面板系统

LA() / LL() / LM() 构建完整 UI，含搜索、试听、选中状态管理。

LA() · LL() · LM()
6

指令路由器

onClickSendBtn() 统一拦截四条指令。P() 预处理缓存文件中的用户选择。

onClickSendBtn() · P()
