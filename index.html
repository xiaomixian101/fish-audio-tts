01 — 功能

六大核心能力

一行指令触发，文字到语音全链路。

A

双维度音色面板

「我的音色」字母索引 + 500+ 公开中文音色按评分排序。实时搜索过滤，一键切换。

B

音色即时试听

每个音色附带样音按钮。后台异步下载，MediaPlayer 播放，选中状态即时切换。

C

API Key 图形化管理

弹窗输入 Key，点击跳转 fish.audio 官网获取，长按复制。config.prop 持久化存储。

D

一键合成 & 发送

POST /v1/tts → s2-pro → 流式读取 mp3 → 转 silk → sendVoice() 直接发送语音消息。

E

30 分钟智能缓存

ConcurrentHashMap + 时间戳，TTL 30 分钟。避免重复请求 API，重启即用。

F

纯原生 UI，零依赖

Dialog + LinearLayout + GradientDrawable。dp 自适应屏幕，无任何第三方库。

05 — 源码

核心函数

DC() — 文字 → POST TTS → 流式读 mp3 → 缓存。

fish-audio-tts.java
void DC(String x, View b) {
    toast("正在转换…");
    new Thread(() -> {
        try {
            var r = new JSONObject();
            r.put("text", x);
            r.put("reference_id", a0);
            r.put("format", "mp3");
            r.put("normalize", true);

            var cn = (HttpURLConnection)
                new URL("https://api.fish.audio/v1/tts")
                .openConnection();
            cn.setRequestMethod("POST");
            cn.setDoOutput(true);
            cn.setRequestProperty("Authorization","Bearer "+a2);
            cn.setRequestProperty("Content-Type","application/json");
            cn.setRequestProperty("model","s2-pro");

            var o = cn.getOutputStream();
            o.write(r.toString().getBytes("UTF-8"));
            o.flush(); o.close();

            var mp = cacheDir+"/tts_"+
                     System.currentTimeMillis()+".mp3";
            var fo = new FileOutputStream(mp);
            var ins = cn.getInputStream();
            byte[] bf = new byte[8192]; int n;
            while((n=ins.read(bf))!=-1) fo.write(bf,0,n);
            fo.close(); ins.close(); cn.disconnect();

            s("last_mp3", mp);
            b.post(()->toast("转换成功"));
        } catch(Exception e){
            b.post(()->toast("转换失败"));
        }
    }).start();
}

06 — 架构

模块分解
