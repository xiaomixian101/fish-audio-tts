核心功能

六大特性，
覆盖全流程

文字转语音

输入任意文字，调用 Fish Audio s2-pro 模型，生成自然流畅的高质量语音。

TTS

API Key 管理

在插件内直接设置 Fish Audio API Key，支持回车保存，安全存储在本地。

配置

音色浏览选择

浏览「我的音色」和「音色列表」，带实时搜索过滤，一键切换当前音色。

Voice

试听播放

选择音色前可点击 ▶ 按钮试听样本音频，支持在线流式播放。

预览

一键发送语音

生成的语音自动转为 Silk 格式，一键以语音消息形式发送给微信好友。

发送

实时搜索过滤

在音色列表中输入关键词，实时过滤匹配结果，快速定位目标音色。

操作指令

三句话搞定一切

01
输入 设置key
弹出 Key 设置面板，填入 Fish Audio API Key 并保存
02
输入 设置音色
加载音色列表，按字母/数字选择，点击试听并设为当前
03
输入 转语音
打开转换面板，输入文字 → 点击转换 → 播放试听 → 发送好友
