六大核心能力

一条聊天指令触发，从文字到语音消息全链路打通。
A

双维度音色面板

「我的音色」字母索引 + 500+ 中文音色按评分排序。实时搜索过滤，一键切换。

B

音色即时试听

每个音色附带样音按钮。后台异步下载，MediaPlayer 播放，不阻塞 UI。

C

Key 图形化管理

弹窗输入 API Key，点击跳转 fish.audio 获取，长按复制链接。config.prop 持久化。

D

合成 & 发送

POST /v1/tts → s2-pro 模型 → 流式读取 mp3 → 转 silk → sendVoice() 直接发送。

E

30 分钟智能缓存

ConcurrentHashMap + 时间戳校验，TTL 30 分钟。避免重复请求 API，重启即用。

F

纯原生 UI

Dialog + LinearLayout + GradientDrawable。dp 自适应全部屏幕，零第三方依赖。

05

核心源码

DC() 函数 — POST TTS 接口，流式读取 mp3 响应并缓存本地。
DC.java
void DC(String x, View b) {
    new Thread(() -> {
        var r = new JSONObject();
        r.put("text", x);
        r.put("reference_id", a0);
        r.put("format", "mp3");
        r.put("normalize", true);

        var cn = (HttpURLConnection)
            new URL("https://api.fish.audio/v1/tts")
            .openConnection();
        cn.setRequestMethod("POST");
        cn.setDoOutput(true);
        cn.setRequestProperty("Authorization", "Bearer " + a2);
        cn.setRequestProperty("Content-Type", "application/json");
        cn.setRequestProperty("model", "s2-pro");

        var o = cn.getOutputStream();
        o.write(r.toString().getBytes("UTF-8"));
        o.flush(); o.close();

        var mp = cacheDir + "/tts_" +
                 System.currentTimeMillis() + ".mp3";
        var ins = cn.getInputStream();
        var fo = new FileOutputStream(mp);
        byte[] bf = new byte[8192]; int n;
        while ((n = ins.read(bf)) != -1) fo.write(bf, 0, n);
        fo.close(); ins.close(); cn.disconnect();

        s("last_mp3", mp);
        b.post(() -> toast("转换成功"));
    }).start();
}
