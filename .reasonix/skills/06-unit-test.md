# 🧪 单元测试生成器

分析源码，识别可测试单元，生成即刻可运行的测试文件。

## 何时使用
- 「帮我写测试」「加单元测试」「生成测试」「测一下这个文件」

## 流程

### 第 1 步：分析源码
识别：公开函数/方法、边界情况（null/空/边界值）、需要 mock 的依赖

### 第 2 步：选择测试框架
- **TS/JS**：vitest 或 jest
- **Python**：pytest
- **Go**：testing 包
- **Rust**：cargo test

### 第 3 步：生成测试
每个函数覆盖：
1. 正常路径 — 正常输入 → 预期输出
2. 边界情况 — null、空、0、负数、极大值
3. 异常处理 — 无效输入 → 合理报错
4. 临界值 — 刚好在有效范围边缘

### 第 4 步：运行验证
```bash
npx vitest run <测试文件>  # 或 pytest、go test
```
测试失败则诊断修复 — 绝不留失败测试。

## 测试模板（vitest）
```typescript
import { describe, it, expect } from 'vitest';
import { 函数名 } from './模块';

describe('函数名', () => {
  it('正常输入应返回预期输出', () => {
    expect(函数名('合法输入')).toBe('预期结果');
  });
  it('应处理空输入', () => {
    expect(函数名('')).toBeNull();
  });
  it('无效输入应抛出异常', () => {
    expect(() => 函数名(null)).toThrow();
  });
});
```

## 注意事项
- 测试小而专注，一个断言对应一个测试
- 测试行为，不要测试实现细节
- Mock 外部服务
