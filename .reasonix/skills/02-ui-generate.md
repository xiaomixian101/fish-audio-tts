# 🎨 UI 生成 — 生产级前端设计

基于 Anthropic 官方 frontend-design (147k⭐) + Open Design (60.6k⭐)。创造独特、生产级的前端界面。

## 何时使用
- 「帮我做一个落地页 / 仪表盘 / 网站」
- 「创建一个 UI 组件」
- 「帮我设计一个漂亮的页面」
- 任何涉及 HTML/CSS/JS、React、Vue 的 UI 需求

## 设计流程

### 第一阶段：设计思考（强制 — 写代码前先想清楚）
1. **目的**：这个界面解决什么问题？谁在使用？
2. **风格**：选一个极致方向 — 极致简约/精炼奢华/极繁主义/杂志编辑风/复古未来主义/有机自然/暗黑电影感...
3. **记忆点**：什么让人**过目不忘**？

### 第二阶段：实现
产出生产级、功能完整的代码，视觉冲击力强、细节打磨精致。

## 美学规则

### 字体排版
- **绝不要用**：Inter、Roboto、Arial、系统字体、Space Grotesk
- **要用**：独特、美丽的字体。展示字体 + 精致正文字体搭配
- 中文推荐：Noto Serif SC、ZCOOL、Ma Shan Zheng 等

### 颜色 & 主题
- **绝不要用**：白底紫色渐变
- **推荐**：大胆双色调、深色暗黑主题、温暖大地色、活力霓虹色

### 动效 & 动画
- HTML 用 CSS 动画；React 用 Motion/Framer Motion
- 重点在高光时刻：页面加载的渐进揭示动画
- **绝不要让页面静止**

### 空间构成
- 不对称、重叠、打破网格的布局
- 大量留白或精细密度 — 绝不中庸

### 背景 & 视觉细节
- 绝不默认纯白/纯灰背景
- 添加渐变网格、噪点纹理、几何图案、颗粒叠加

## 绝对不要做的事
- ❌ Inter/Roboto/Arial 字体
- ❌ 白底紫色渐变
- ❌ 千篇一律的居中卡片布局
- ❌ 没有任何动画
- ❌ Bootstrap 风格
- ❌ 通用 AI 审美

## 输出格式
完整、独立的 HTML 文件（或 React 组件），CSS 内联，真实字体 CDN 加载，浏览器打开即惊艳。
