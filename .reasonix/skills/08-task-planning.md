# 📐 任务规划 (Manus 风格)

创建并维护持久化计划文件，进度跨对话保持，用户随时可见。

## 何时使用
- 3 步以上的任务
- 用户明确要计划
- 构建功能、调试复杂问题、多文件重构

## 工作流程

### 1. 创建计划 `.reasonix/plan.md`
```markdown
# [任务名称]

**状态：** 进行中 | 已完成 | 已阻塞
**创建时间：** [时间戳]
**目标：** [一句话]

## 步骤
- [ ] 步骤 1
- [ ] 步骤 2
- [ ] 步骤 3

## 当前进度
[正在做什么]

## 决策记录
- [决策及原因]

## 备注
[上下文]
```

### 2. 持续更新
- 完成步骤标 `[x]`，更新当前进度，记录决策

### 3. 会话恢复
若 plan.md 存在且「进行中」，读取并从中断处恢复。

### 4. 完成
状态→已完成，加总结。

## 注意事项
- 步骤粒度要细 — 一个勾选框 = 一个有意义操作
- 记录所有非显而易见的决策
- 若阻塞，说明原因和可选方案
